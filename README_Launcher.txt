FIRST IMAGE STUDIO ERP - AUTO-START LAUNCHER BUNDLE
===================================================

Included Files:
1. Start_ERP.bat            -> Starts the backend server and opens Chrome at http://localhost:4580
2. Start_ERP_Silent.vbs     -> Starts the backend server silently in the background (no CMD window)
3. Install_Startup.bat      -> Automatically creates a Startup shortcut in Windows Startup folder

HOW TO USE:
1. Extract these files directly into your ERP folder (the exact folder containing server.js).
2. Double-click 'Install_Startup.bat' ONCE to enable automatic startup when Windows boots.
3. To start manually anytime, double-click 'Start_ERP.bat' (or 'Start_ERP_Silent.vbs' for background mode).
